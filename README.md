# Joke generator

A small browser project demonstrating asynchronous API requests and basic DOM interaction. The interface is in Catalan; joke text comes from an external API and may be in another language.

## Run

Open `index.html` in a browser or serve the directory with `python -m http.server 8000`. The page requests a single joke on load and when the user presses the button. An error message is shown if a request fails.

## Structure and scope

`index.html` contains the markup and JavaScript; `style.css` supplies presentation. There is no backend, account system, or API key. It is a finished small learning exercise, not a major portfolio showcase. API availability/content are external dependencies.
